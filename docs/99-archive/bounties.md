# Bounties (Archived Reference)

Archived summary of Numerai's bug/security bounty program (see [numer.ai](https://numer.ai) for the live program).

- **Bug bounties:** 0.1–1 NMR (cosmetic: styling, broken links, typos) to 1–5 NMR (incorrect data / scoring / payouts, or broken services).
- **Security vulnerabilities:** 0.1–2 (low), 2–10 (moderate), 10–100 (high), 100+ NMR (catastrophic). High priority: account takeover, credential leaks, loss of funds, tournament-exploit payouts.
- **Reporting:** email `security@numer.ai` with subject `[Security Report] ...`; include a step-by-step proof-of-concept.

Relevance to this repo: metric/scoring bugs are 1–5 NMR-class issues — treat evaluation correctness as a first-class bug class.
