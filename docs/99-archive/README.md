# Documentation Archive

This directory preserves provenance that may explain past decisions but does not
describe the current system. Current behavior is owned by code and tests; current
documentation is routed through [`CODEBASE.md`](../../CODEBASE.md) and
[`docs/DOCS_README.md`](../DOCS_README.md).

## Contents

- [`dashboard-history-2026-08.md`](dashboard-history-2026-08.md) records the
  dashboard architecture transition and its durable outcome.
- [`design-records-2026-08.md`](design-records-2026-08.md) records completed
  design work whose implementation contracts now live in the active SSOT docs.
- [`super-research.prompt.md`](super-research.prompt.md) is retained historical
  research context.
- `raw-source/` contains immutable source material preserved for provenance. It
  is not maintained and may contain obsolete statements or links.

Archived material cannot override [`AGENTS.md`](../../AGENTS.md),
[`ARCHITECTURE.md`](../../ARCHITECTURE.md),
[`CONTRIBUTING.md`](../../CONTRIBUTING.md), the Numerai canon, or the evaluation
specification.
